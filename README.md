FuMOGAE Project Description

The Dataset folder contains the METABRIC breast cancer cohort consisting of 1,253 patient samples. The dataset includes five complementary modalities: Clinical data, Copy Number Alteration (CNA), Gene Expression (GSE), DNA Methylation, and miRNA Expression.

The METABRIC dataset is used to train and evaluate the FuMOGAE model for multi-modal breast cancer subtype classification. The provided breast cancer subtype labels—LumA, LumB, Her2-enriched, Basal-like, and Normal—serve as ground truth for evaluating the classification performance of the proposed framework.
